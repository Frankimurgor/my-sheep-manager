# Privacy Policy — My Sheep Manager

**Last updated:** October 14, 2026

## Data Collection

My Sheep Manager does not collect, transmit, or share any personal data. The app has no analytics, no ads, no tracking, and no network requests.

## Data Storage

All data you enter (sheep records, health events, weights, breeding, lambing, money, tasks) is stored locally on your device using Android's private app storage. This data is never transmitted anywhere.

## Permissions

- **Camera & Photos**: Used only when you choose to add a photo to a sheep's profile. Photos are stored locally.
- **Storage (if requested)**: Used only for CSV export, which opens the Android share sheet to send a file to an app you choose.

## Third Parties

None. My Sheep Manager does not integrate with any third-party service.
